This companion paper asks whether learned models reuse a recurring functional scaffold while each input instantiates a different semantic causal subcircuit on it. The proposed shared object is a recurrent role graph—source/current operation, carried state, the next live address or transition read, a semantic writer, updated carried state, and the unchanged native consumer—not one tensor layout or fixed list of physical sites. The working class name is **scaffolded recurrent semantic circuits**.

The [`outline.md`](outline.md) separates that claim from two weaker facts: model weights are fixed while activations change, and architecture graphs recur by construction. The primary E1–E3 selections are prospective and lane-specific: each freezes a finite causal selection rule before held evaluation. Later relation, role-alignment, query, and feedback diagnostics have their own post-hoc or competence boundaries. The first-wave modules expose different causal resolutions. Missing mediation fields remain missing evidence; they are not converted into negative results or silently treated as measured.

The strongest prior diffusion motivation is the causal format×ontology, cross-prompt structural-grammar, and object×scene edit record. Those studies show recurrent route or composition grammar alongside prompt-, scene-, and time-dependent support. The passive 206-node skeleton is useful infrastructure, but it is not the central evidence for a learned functional scaffold.

The strict four-quadrant certificate from the companion [space-and-time paper](../space-and-time-circuits/paper.md) is an optional circuit subtype, not a criterion for this architecture. A scaffold may contain a local writer, a redundant store, a distributed path, or a mixture. “Autoregressive” names an execution regime; transformer and SSM name architectures that can both implement it.

Results will be reported as raw observations, trends, convergent trends, working inferences, and only then any explicitly bounded terminal claim. First-wave hard gates are limited to evidence integrity, valid instrumentation, and safe execution.
