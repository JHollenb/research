# Figures

Both figures are generated by `make_figures.py` (light single-process matplotlib; no models
loaded), reading values directly from the two preregistered experiments' frozen `analysis.json`
reports. Paths below are relative to `~/domains/`.

```bash
cd ~/domains/research/papers/pass-indexed-baseline/figures && python3 make_figures.py
```

## Figure 1 — Per-pass native-answer drift across arms

`fig1-per-pass-drift.png`. Grouped bars of the median absolute drift of the later-turn native
answer log-probability versus the fixed single-turn parent, at passes 1–3 (pass 0 is the install
turn, drift 0 by construction). Arms: Qwen2.5-1.5B base, Qwen2.5-1.5B-Instruct raw,
Qwen2.5-7B-Instruct raw, and Qwen2.5-1.5B-Instruct under the chat template. The raw arms drift
~1.2–3.6 nats per pass; the chat-template arm is ~0, i.e. formatting-matched continuation removes
the drift.

- Data (field `R0_drift.median_abs_drift_by_pass`):
  - base 1.5B — `saturn/experiments/2026-10-02-pass-indexed-baseline/results/pass-indexed-35d4adaeed36/analysis.json`
  - 1.5B-Instruct raw — `saturn/experiments/2026-10-05-pass-indexed-instruct-7b/results/q15i_raw_full-23194c4f1d09/analysis.json`
  - 7B-Instruct raw — `saturn/experiments/2026-10-05-pass-indexed-instruct-7b/results/q7i_raw_full_bf16-8243f04af7c7/analysis.json`
  - 1.5B-Instruct chat — `saturn/experiments/2026-10-05-pass-indexed-instruct-7b/results/q15i_chat_full-2e4198b3de14/analysis.json`
  - (the 7B-Instruct chat arm, `q7i_chat_full_bf16-1d9876bd8f78`, is likewise ~0 and is omitted to keep four bars per pass.)

## Figure 2 — Install effect vs the fixed parent vs the pass-indexed native

`fig2-install-vs-baseline.png`. For the Qwen2.5-1.5B base model, the measured effect of a late
key/value install on the native answer log-probability at passes 1–3, scored against the fixed
single-turn parent and against the pass-indexed native. Median bars with the per-scene points
overlaid, and the ±1-nat threshold lines. Against the fixed parent the pass-1 median is +1.24 nats
(reads as "installs"); against the pass-indexed native it is −0.13 (no install) — the baseline
choice flips the conclusion.

- Data: `saturn/experiments/2026-10-02-pass-indexed-baseline/results/pass-indexed-35d4adaeed36/analysis.json`,
  field `R2_pass_indexed_install` (`per_pass_median.{eff_fixed,eff_reb}` for the medians;
  `flip_rows.{effect_vs_fixed,effect_vs_rebaselined,pass,scene}` for the per-scene points).

Style: white background, Okabe–Ito colour-blind-safe palette, 300 dpi, axis labels with units,
no in-image titles (captions live in the paper).
