## The computation to replace

The final mixer receives the live output of the preceding native scan and post block. Its entry is `[batch,64,48]`. Source-qualified normalization, input projection, causal convolution and selection produce `u, dt, B, C, G`; the compiled program owns independent copies of the learned parameters. For each bit position t:

```
A = -exp(a_log)
D_t = exp(dt_t[...,None] * A)
W_t = (dt_t * u_t)[...,None] * B_t[:,None,:]
H_t = D_t * H_(t-1) + W_t
r_t = sum_state(H_t * C_t[:,None,:])
M = entry + Linear_out((stack(r_t) + d*u) * G)
```

`H` starts at zero on every model call. The compiled evaluation retains a current `[batch,96,4]` recurrent state and consumes it at each row. It avoids complete `[batch,64,96,4]` decay, writer and state trajectories. A `[batch,64,96]` readout buffer keeps the output projection's batched geometry unchanged. Old/new states and temporary decay, writer and product buffers also occupy memory; 384 persistent state elements are not the total peak working set.

The source scan uses associative doubling, while this primitive evaluates the diagonal recurrence sequentially. These are the same real-arithmetic state update with different floating-point association. All signed head differences and any decoded-state divergence remain observations. The primitive runs without an autograd tape; training behavior is outside its ABI.

The compiled candidate replaces `mixers[2]` before execution. It must neither call nor retain the removed native final mixer. Its own parameter storage must not alias that mixer. The first two native scans and all later post/flag/register/store consumers remain part of the native model. A replacement installed only after native H was already computed would not qualify as this lowering.

Native first calls supply four SSA captures, four untraced exact-input controls and four exact root replays. Four typed dt copies calibrate the intervention; four typed scaled-dt branches test the sealed compiled predictions. Every branch retains all eleven native output heads.

The budget is **32 physical full-model calls, four root replays and eight typed suffix branches: 44 logical items**. It includes four native baseline second calls, eight compiled baseline calls, eight compiled clock calls and four native clock second calls. Native clock first calls are suffix replays rather than additional full-model calls. Compiled prediction sealing precedes those clock replays in the execution ledger.

Each of the 16 compiled calls runs the recovered component once through the public Saturn Adapter and Session continuation. These transitions are nested inside the full-model calls, so they do not add to the 44 macro work items. Together with the eight native intervention receipts, the panel is expected to retain 24 public execution receipts.

Independent shape instrumentation is scoped to the replaced mixer: record operation outputs with full trajectory geometry in the native implementation and their absence in the compiled one. Output-shape occurrences include views and do not measure distinct allocations or allocator peak. Report row-buffer geometry separately from process RSS and timing. A reduction in trajectory storage is not a parameter reduction or a speed claim. Retain full wall-time and resource observations even if the sequential version is slower.

Only identity, shape/device/finite-value contracts, exact replay/copy calibration, immutable prediction seals and state lineage can stop mechanics. Approximation errors, threshold decisions and speed are observations during discovery. A future bounded substitution claim needs its own declared consumer-aligned numerical contract.

## What would advance the moonshot

A useful outcome is a source-bound, donor-free clock/readout primitive that predicts native counterfactual responses and survives a dependent continuation while avoiding the dense state trajectory. The symbol table should expose its entry, equations, live state, bit clock, native consumer, observed differences and source provenance.

The recurrent state remains 96 channels by four modes. Time-varying C readers and mode-dependent retention can expose components invisible to a current 48-feature readout, so the earlier 384-to-48 intervention lowering does not imply a 48-state recurrent machine. Finding a smaller sufficient state, deriving input-conditioned arithmetic roles, learning address applicability and transferring those roles to other checkpoints remain later scientific work.
