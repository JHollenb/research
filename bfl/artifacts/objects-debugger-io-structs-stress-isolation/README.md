# Objects Become Debugger I/O proof bundle

This bundle contains the local proof artifacts for the integrated object-address experiment. It covers three stages: inverse object mapping, a live object registry and edit battery, and typed manifest plus deep-map, stress, and isolation tests.

The PNG files are the retained visual proof panes and zooms. The JSON files are compact metric ledgers that preserve the measurements used by the standalone report. The copied run receipts preserve the execution contract, model, seed, route, and resource metadata. The source-address registry is the concrete per-object address artifact used by the edit battery.

Run `python verify.py` from this directory. The verifier checks that all three stages have their receipts and proof images, that the manifest readback fingerprint matches, and that the headline measurements are present and internally consistent.

## Artifact groups

- Stage 1: inverse object map, object-selective lexical rows, exact no-op, and scene proof panes.
- Stage 2: lexical and spatial address registry, recolor/replace/reshape evidence, movement and layering panes, and the wrong-address correction.
- Stage 3: durable manifest proof, conditioner-depth summary, dose and payload-portability panes, native composition panes, and isolation proof across both seeds.

All links needed to inspect this bundle are local to this directory or to the standalone report. No external experiment directory is required to interpret the measurements.
