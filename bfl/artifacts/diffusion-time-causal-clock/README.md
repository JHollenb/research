# Diffusion-time causal clock: evidence bundle

This bundle preserves the resume-at-k, cheap-deep, character-pinning, face identity, regional sustained, and image-token address records used by the report. The montages are compact visual artifacts; the JSON and Markdown records retain the numeric measurements and caveats.

The verifier checks exact replay, timing values, identity curves, regional tradeoffs, and image-stream role labels. It does not interpret whole-image identity scores as face-crop recognition.

Run `python verify.py` from this directory.
