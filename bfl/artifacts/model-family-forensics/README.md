# Model-family forensics: evidence bundle

This bundle preserves the model-family wiki and the three narrative forensic records used by the standalone report. They retain the exact custody scope, tensor inventories, parameter counts, activation CKA, principal-angle witness, scheduler mapping, and VAE byte-identity results.

The verifier checks structural claims only. It does not infer semantic lineage from geometric similarity or absence of a witness signal.

Run `python verify.py` from this directory.
