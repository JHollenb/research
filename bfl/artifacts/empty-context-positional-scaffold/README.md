# Empty-context positional scaffold: evidence bundle

This bundle preserves the context-pad report and execution receipt together with the two explanatory source records. The raw evidence records zeroing, matched-position controls, empty-to-empty substitution, unrelated-padding substitution, and per-step damage windows.

The verifier checks the bounded numeric claims and the tone-bank interpretation. It does not treat the result as a universal padding or positional-encoding law.

Run `python verify.py` from this directory.
