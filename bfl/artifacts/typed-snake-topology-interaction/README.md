# Typed snake topology and interaction residual: evidence bundle

This bundle preserves the native topology-repair report and visual branches, together with the 102-branch interaction-residual panel. The topology raw report records the typed route, full and half doses, ablation, wrong-axis control, and held-out seeds. The interaction analysis records native pair progress, additive composition, dose, timing, site, sign, and sham controls.

The original invalid S-curve donor is represented by the source artifacts and is called out as a caveat in the standalone report. The verifier checks the corrected target-native result.

Run `python verify.py` from this directory.
