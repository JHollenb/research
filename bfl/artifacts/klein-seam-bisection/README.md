# Klein seam bisection proof bundle

This bundle preserves the two stages of the Base-to-distilled seam experiment: the sealed Base capture and the distilled recipient repair. The raw JSON reports and receipts are copied from the recorded jobs; the PNGs are representative held-out repair outputs; `source-ledger.md` preserves the detailed experimental ledger.

Run `python verify.py` from this directory. The verifier checks both stage reports, the selected seam evidence, the held-out `1/4` result, exact receipt presence, and all representative images.
