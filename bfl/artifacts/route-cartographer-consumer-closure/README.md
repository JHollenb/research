# Route cartographer and consumer closure: evidence bundle

This bundle preserves the route capture, signatures, multidomain cartographer report, native endpoint outcomes, held-out predictors, and future-forecast records. The evidence distinguishes address prediction from native-consumer promotion.

The verifier checks capture size, entropy ranges, selector accuracy, promotion/rejection, rollback, single-token route failures, and whole text-state closure.

Run `python verify.py` from this directory.
