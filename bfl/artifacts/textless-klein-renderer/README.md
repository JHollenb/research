# Textless Klein renderer proof bundle

This bundle contains the raw structured-frontend report, execution receipt, representative SceneGraph and robot/JSON held-out images, and the full BFL-next ledger. It preserves both strong and failed structured cases rather than reducing the experiment to its best image.

Run `python verify.py` from this directory. The verifier checks the mixed held-out progress values, embedding-versus-image distinction, controls, and retained images.
