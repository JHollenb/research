# Nonlinear interaction compiler proof bundle

This bundle contains separate raw reports for the learned mixer and the native interaction-residual panel, their execution receipts, native/additive/interaction images, and the BFL-next experimental ledger. The separation preserves the positive native interaction result and the negative learned-composer result.

Run `python verify.py` from this directory. The verifier checks both raw reports, the held-out mixer comparison, the native interaction dose evidence, and the retained image controls.
