# Semantic-circuit object interface proof bundle

This bundle is the local evidence package for the standalone demo [Semantic Circuit Objects](../../demos/semantic-circuit-object-interface.md). It synthesizes the route-circuit, object-address, held-out algebra, isolation, and value-level debugger results into one inspectable proof set.

The central chain is: a native semantic circuit identifies a causal route; controlled donor/base contrasts localize lexical rows on that route; image probes join those rows to spatial effects; a typed manifest records the address and its evidence; and native suffix replay uses the record to read, transform, write, isolate, or delete an object without changing model weights.

## Artifact groups

- `circuit-panel-ledger.json`, `circuit-panel-proof-sheet.png`, `route-certificate.json`, and `route-certificate.md` establish the route-level foundation and its consumer-facing controls.
- `inverse-object-map.json`, `object-edit-battery.json`, `source-address-registry.json`, `object-manifest-proof.json`, `deepmap-summary.json`, and `isolation-summary.json` show how a route becomes a typed object symbol.
- `inverse-object-proof.png`, `object-registry-proof.png`, `wrong-address-proof.png`, `dose-proof.png`, and `isolation-proof.png` show object-selective edits, payload/address separation, dose limits, and text-route isolation.
- `heldout-algebra-report.json`, `heldout-algebra-run-receipt.json`, `heldout-catmug-proof.png`, `heldout-parrotbike-proof.png`, `displacement-strip.png`, `cross-scene-port-proof.png`, and `readout-timing-proof.png` show held-out registry behavior, portable displacement, and late-site readout.
- `isolation2-first-report.json`, `isolation2-rerun-report.json`, `pose-isolation-proof.png`, and `role-backfill-proof.png` show composition-preserving context and the recorded extractor correction.
- `value-debugger-report.json`, `value-debugger-run-receipt.json`, `value-write-proof.png`, `register-semantics-proof.png`, `subject-prior-proof.png`, and `value-debugger-proof-sheet.png` show the two-read, one-subtract, one-write operation and its controls.

The visual panes are primary when ROI scalars and the rendered result disagree. All GPU results are exploratory: two seeds, one pinned FLUX.2 Klein 4B recipe, shared scene grammars, and no certified semantic-object tier.

Run `python verify.py` from this directory to check the local ledger, receipts, manifests, and representative proof files.
