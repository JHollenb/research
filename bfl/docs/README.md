# BFL Research Documentation

This directory contains supporting documentation for the Black Forest Labs work on `main`. It holds the certified-circuits paper and the checkpoint-scoped tracer atlas.

- [Certified semantic circuits in FLUX.2](certified-semantic-circuits/README.md): the paper on the certified distributed semantic route in FLUX.2 Klein 4B, its figures, and the offline Pythia verifier.
- [BFL tracer documentation](tracer/README.md): seven pinned Black Forest Labs components, model-specific profiles, role budgets, live-assay boundaries, and source evidence.

The first-look narrative is in the [BFL research README](../README.md), and the executable evidence is in the [BFL demos](../demos/).
