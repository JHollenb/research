# Research

This directory contains the committed research notes, standalone demonstrations, and evidence bundles behind the model work in this repository.

## Black Forest Labs

The main branch studies FLUX as an executable image program rather than a sealed `forward()` call. The work captures typed boundaries from conditioner through denoiser, scheduler, and VAE; forks matched futures from one parent; changes a route, phase, carrier, or state; and asks the native image consumer what actually changed.

The main research path has seven connected results: exact phase-resident serving, consumer-closed route promotion, cross-family conditioner compilation, multi-model structural tracing, recipient-native repair, typed snake and interaction controls, and real hotpatch/counterfactual futures. Supporting main-branch demos turn routes into typed objects, map object properties into debugger I/O, and broaden the route-level semantic panel.

The durable claim is deliberately bounded. FLUX execution can be made typed, branchable, replayable, and consumer-closed across the pinned models in the tracer cohort. The shared `joint.*` vocabulary is a useful instrumentation grammar and search order, while payloads, semantic meanings, and causal effects remain checkpoint- and topology-local.

Start with the [BFL research README](bfl/README.md) for the main-branch narrative, model/checkpoint scope, `joint.*` mapping, and speed accounting. The [demo reports](bfl/demos/) contain the native-consumer experiments, [tracer documentation](bfl/docs/tracer/README.md) contains the checkpoint-scoped instrumentation cards, and [artifacts](bfl/artifacts/) contains receipts, proof sheets, and verification scripts.
